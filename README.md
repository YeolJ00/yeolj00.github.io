# yeolj00.github.io

Personal website of Jooyeol Yun — plain static HTML, no build step.

- `index.html` — homepage (bio, publications, education). Edit it directly.
- `404.html` — not-found page.
- `images/` — profile photo and paper teasers.
- `research/` — standalone project pages for papers.
- `personal-projects/` — standalone personal project pages.
- `.nojekyll` — tells GitHub Pages to serve files as-is (no Jekyll build).

Deploy: push to `main`; GitHub Pages serves the repo root directly.
